LEVER 01

Leave the terminal

Zero config, biggest change. Claude Code also ships as a Windows desktop app, a VS Code / JetBrains extension, and a web app at claude.ai/code. Real scrollback, collapsible tool blocks, no black void.

If it's the terminal hurting your eye and not the colors — stop here. The rest of this page is for people who want to stay in the terminal.

LEVER 03

/config → theme

Claude Code has its own theme setting, separate from the terminal. The key choice is hardcoded vs. ANSI.

theme: darkignores your scheme
⏺ Update(auth.controller.ts) ⎿ Updated with 7 additions + @Throttle({ limit: 5 }) - @Post('login') Your beautiful Catppuccin palette sits underneath, unused. Claude Code paints its own greens and reds on top.
Claude Code ships fixed hex values. Consistent everywhere, but clashes with whatever scheme you picked.
theme: dark-ansidefers to terminal
⏺ Update(auth.controller.ts) ⎿ Updated with 7 additions + @Throttle({ limit: 5 }) - @Post('login') Claude Code emits ANSI slots 1–15. Your scheme fills them. One palette, whole terminal. Nothing clashes.
Pick this after Lever 02. Change scheme later and Claude Code follows automatically — no reconfiguring.

Full list in /config: dark · light · dark-ansi · light-ansi · dark-daltonized · light-daltonized. The daltonized pair swaps red/green for blue/orange — worth trying regardless of color vision, red-on-black is the harshest pairing on the list.

LEVER 04

tweakcc Piebald-AI/tweakcc · 2.4k ★

The repo you were asking about. It patches the installed Claude Code CLI directly — custom themes with an HSL color picker, custom spinners, 200+ thinking verbs, regex input highlighters, and it can strip the ASCII box around the prompt.

StockASCII box + gray user text
✻ Cogitating… (4s · esc to interrupt) ╭────────────────────────────────────╮ │ > fix the login bug │ ╰────────────────────────────────────╯ > earlier message, unreadable gray > another one, same flat gray
Box eats 3 lines of vertical space. Your own messages render dim gray — hard to find when scrolling back.
tweakcc'dborderless + colored
⠹ Percolating… (4s · esc to interrupt) ❯ fix the login bug ❯ earlier message, easy to spot ❯ another one, scannable
Border removed, custom spinner + verb, user messages recolored. Denser and easier to scan back through.
// interactive TUI — pick colors, verbs, spinner
npx tweakcc

// after every Claude Code update, reapply:
npx tweakcc --apply

Tradeoff, stated plainly. tweakcc rewrites Claude Code's bundled cli.js in place. Every Claude Code update overwrites the patch. Your settings survive in ~/.tweakcc/config.json, but you must re-run --apply. If Claude Code ever behaves strangely after a version bump, unpatch before filing a bug.

APPLY

The actual config

%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json

// goes inside "profiles", replacing the empty "defaults": {}
"defaults": {
  "colorScheme": "Catppuccin Mocha",   // paste scheme into "schemes": [] first
  "font": { "face": "JetBrainsMono Nerd Font", "size": 11, "weight": "normal" },
  "opacity": 92,               // 92 reads best; below 80 hurts contrast
  "useAcrylic": true,          // blur behind — needed for opacity to look good
  "padding": "16",             // biggest single readability win
  "cursorShape": "filledBox",
  "scrollbarState": "hidden",  // Claude Code manages its own scroll
  "antialiasingMode": "grayscale" // kills color fringing on dark bg
}

Order of operations

  1. Install JetBrainsMono Nerd FontFrom ryanoasis/nerd-fonts releases → JetBrainsMono.zip. Select all .ttf → right-click → Install for all users. Must be the Nerd Font build, not plain JetBrains Mono, or powerline glyphs stay as tofu.
  2. Add the color schemeCopy the Mocha JSON from catppuccin/windows-terminal into the "schemes": [] array — currently empty on your machine.
  3. Paste the defaults blockWindows Terminal hot-reloads on save. No restart.
  4. Set Claude Code to dark-ansi/config → Theme → dark-ansi. Now the scheme drives everything.
  5. Optional: tweakccnpx tweakcc — only if you still want the input box border gone.

BONUS

“A lot of text” is a separate problem

Color fixes harsh. It does not fix volume. Three levers for that:

SettingNowEffect
/output-styleExplanatoryExplanatory adds a teaching block to every answer by design. default removes them.
/cavemanfullAlready cutting roughly 75%. /caveman ultra goes further.
/config → verboseonOff collapses long tool output to a summary line — usually the single biggest source of scroll.
Live preview approximates Windows Terminal rendering — acrylic blur and font hinting differ slightly on the real thing. Every setting shown is reversible; back up settings.json before editing.
